# Liberty Walk F40

Trang web trình diễn Ferrari F40 với Vite, GSAP và mô hình 3D Sketchfab của vecarz.

## Chạy dự án

Yêu cầu Node.js 22.12 trở lên.

```bash
npm ci
npm run dev
```

Build: `npm run build`. Tài nguyên ảnh và font đã có trong `public/`; có thể kiểm tra và tải lại bằng `npm run assets`.

Mô hình 3D được nhúng từ Sketchfab và cần kết nối mạng. Đây là bản trình diễn độc lập, không phải website chính thức của Liberty Walk. Quyền đối với hình ảnh, thương hiệu và mô hình thuộc về các chủ sở hữu tương ứng; xem các liên kết ghi nguồn trên trang.
